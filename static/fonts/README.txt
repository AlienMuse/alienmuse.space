Orbitron: the original font (Google Fonts, OFL 1.1; Reserved Font Name "Orbitron"), only wrapped as WOFF2
(OFL-Orbitron.txt).
TGP Pagella, TGP Pagella Math: subsets of TeX Gyre Pagella and TeX Gyre Pagella Math (GUST e-foundry), renamed
for the GUST Font License (GUST-FONT-LICENSE.txt).
TGP Symbol Math: a subset of STIX Two Math (The STIX Fonts Project Authors), renamed for the SIL Open Font
License 1.1 (OFL-STIX-Two.txt); it supplies the signs Pagella Math lacks.
